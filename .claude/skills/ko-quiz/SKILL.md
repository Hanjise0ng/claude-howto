# 한국어 학습 가이드 퀴즈

한국어 학습 가이드(`ko/`)의 한 장을 골라 8문제로 이해도를 확인합니다. 모든 대화는 한국어로 진행합니다.

## 지켜야 할 것

- **문제를 지어내지 않는다.** [references/question-bank.md](references/question-bank.md)에 있는 문제만 낸다.
- **정확히 채점한다.** 보기 순서를 섞은 뒤 정답이 몇 번째인지 기록하고, 그 기준으로 채점한다.
- 해당 장의 README가 없으면 문제를 내지 말고 저장소 구조를 확인해 달라고 알린다.

## 1단계: 장 정하기

인자로 장이 주어지면 아래처럼 연결한다.

| 인자 | 장 | 파일 |
|---|---|---|
| `0`, `시작`, `준비` | 0장 시작 전 준비 | `ko/00-getting-started/README.md` |
| `1`, `슬래시`, `명령` | 1장 슬래시 명령 | `ko/01-slash-commands/README.md` |
| `2`, `메모리` | 2장 메모리 | `ko/02-memory/README.md` |
| `3`, `스킬` | 3장 스킬 | `ko/03-skills/README.md` |
| `4`, `서브에이전트`, `에이전트` | 4장 서브에이전트 | `ko/04-subagents/README.md` |
| `5`, `mcp` | 5장 MCP | `ko/05-mcp/README.md` |
| `6`, `훅` | 6장 훅 | `ko/06-hooks/README.md` |
| `7`, `플러그인` | 7장 플러그인 | `ko/07-plugins/README.md` |
| `8`, `체크포인트`, `안전장치` | 8장 체크포인트와 안전장치 | `ko/08-checkpoints/README.md` |
| `9`, `고급` | 9장 고급 기능 | `ko/09-advanced-features/README.md` |
| `10-1`, `cli 기초` | 10장 CLI ① 기초 | `ko/10-cli/README.md` (Part 1) |
| `10-2`, `cli 심화`, `ci` | 10장 CLI ② 심화 | `ko/10-cli/README.md` (Part 2) |

인자가 없으면 AskUserQuestion으로 고르게 한다. 보기는 4개까지만 되므로 단계별로 나눈다.

- 질문 1 (header: "단계"): "어느 단계의 퀴즈를 풀까요?" → "1단계 기초 (0·1·2·8·10-1장)", "2단계 자동화 (3·6·4·5장)", "3단계 고급 (9·10-2·7장)"
- 질문 2: 고른 단계 안의 장을 보기로 보여 준다. 1단계는 장이 5개라서 "0장", "1장", "2장", "8장 또는 10-1장"으로 묶고, 마지막을 고르면 둘 중 하나를 다시 묻는다.

## 2단계: 장 내용 읽기

고른 장의 README **하나만** 읽는다. 그리고 문제 은행에서 그 장의 문제 8개를 찾는다.

## 3단계: 시점 묻기

AskUserQuestion (header: "시점"): "이 장을 공부하기 전인가요, 후인가요?"

1. "공부 전 (사전 테스트)"
2. "공부 중 (중간 점검)"
3. "공부 후 (마무리 확인)"

## 4단계: 문제 내기

8문제를 **한 번에 2문제씩, 4번에 나눠** AskUserQuestion으로 낸다.

- 보기 순서는 **문제마다 무작위로 섞는다.** 문제 은행 순서대로 내거나 정답을 항상 첫 번째에 두지 않는다.
- 각 묶음에 답하면 바로 문제별로 맞았는지 알려 주고, 틀렸으면 정답과 해설을 보여 준다.

## 5단계: 결과 알려 주기

아래 형식으로 결과를 보여 준다.

```markdown
## 📊 퀴즈 결과: [장 이름]

**점수: [맞힌 수]/8** · [등급]

| # | 주제 | 결과 |
|---|---|---|
| 1 | [문제 요약] | ✅ / ❌ |

### 다시 볼 곳
- ❌ Q[번호]: [정답 요약] → [장 README]의 "[복습 위치]"

### 다음 할 일
[시점별 안내]
```

**등급:** 8점 완벽 / 6~7점 잘함 / 4~5점 복습 필요 / 0~3점 처음부터 다시

**시점별 안내:**

- 공부 전: 틀린 문제의 주제를 중심으로 읽으라고 안내한다.
- 공부 중: 틀린 부분의 실습 미션을 다시 해 보라고 안내한다.
- 공부 후: 6점 이상이면 학습 순서상 다음 장을 안내하고(`ko/README.md`의 학습 순서표 기준), 5점 이하면 틀린 부분의 실습 미션부터 다시 하라고 안내한다.

## 6단계: 다음 행동 묻기

AskUserQuestion: "다음에 무엇을 할까요?"

1. "같은 장 다시 풀기"
2. "다음 장 퀴즈"
3. "틀린 개념 설명 듣기" (틀린 문제의 개념을 해당 README 내용으로 쉽게 설명한다)
4. "그만하기"
