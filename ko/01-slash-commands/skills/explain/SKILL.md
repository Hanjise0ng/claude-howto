# 신입 눈높이 설명

설명할 대상: $ARGUMENTS

대상이 이 프로젝트의 클래스나 파일이면 먼저 해당 파일을 찾아 읽은 뒤 설명하세요.
아래 형식을 지켜 주세요.

1. **한 줄 요약**: 이것이 무엇을 하는지 한 문장으로
2. **비유**: 일상생활에 빗대어 한두 문장으로
3. **핵심 포인트 3가지**: 신입이 꼭 알아야 할 것만
4. **코드에서 보기**: 관련 코드 위치(파일:줄)와 짧은 발췌
5. **면접 대비**: 이 내용과 관련해 면접에서 나올 만한 질문 1개
