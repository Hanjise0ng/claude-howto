# 버그 찾기

조사할 증상: $ARGUMENTS

다음 순서로 진행하세요. **코드를 고치기 전에 반드시 2~4단계 결과를 먼저 보여 주고 허락을 받으세요.**

1. **재현**: 어떤 요청이나 상황에서 문제가 생기는지 정리
2. **추적**: 요청이 지나가는 Controller → Service → Repository 경로와 관련 파일
3. **원인**: 문제가 생기는 정확한 줄과 이유 (신입이 이해할 수 있는 말로)
4. **수정안**: 고치는 방법 1~2가지와 각각의 장단점, 추천안
5. **수정 후 확인**: 허락을 받아 고친 뒤 `./gradlew test`를 실행하고, 확인용 `curl` 명령을 알려 주기
