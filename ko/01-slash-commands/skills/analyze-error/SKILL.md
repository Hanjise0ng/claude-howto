# 에러 분석

분석할 에러: $ARGUMENTS

1. **한 줄 요약**: 이 에러가 무슨 뜻인지 쉬운 말로
2. **핵심 줄**: 스택 트레이스에서 봐야 할 줄 (이 프로젝트의 `com.example` 패키지 줄을 먼저)
3. **원인 후보**: 가능성이 높은 순서로 최대 3개
4. **관련 파일**: 프로젝트에서 열어 봐야 할 파일과 줄
5. **해결 순서**: 신입이 따라 할 수 있는 단계별 확인 방법
6. **다음에 피하는 법**: 같은 에러를 막는 습관 한 가지

코드는 고치지 말고 분석만 하세요.
