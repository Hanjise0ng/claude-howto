# 📖 용어집

가이드를 읽다가 모르는 단어가 나오면 여기서 찾아보세요. 각 분야 안에서는 가나다순이 아니라 **처음 만나는 순서**로 적었어요.

## 터미널 기초

| 용어 | 쉬운 설명 | 예시 |
|---|---|---|
| 터미널 | 글자로 컴퓨터에 명령하는 창. 마우스 대신 키보드로 폴더를 열고 프로그램을 실행해요 | Windows Terminal, macOS 터미널 |
| 셸(Shell) | 터미널 안에서 명령을 알아듣는 프로그램 | Bash, PowerShell, zsh |
| 경로 | 파일이 있는 위치를 적은 주소 | `~/board-api/src` |
| `~` | 내 홈 폴더를 줄여 쓴 기호 | `C:\Users\내이름` 또는 `/Users/내이름` |
| `cd` | 폴더 이동 (change directory) | `cd ~/board-api` |
| `ls` | 폴더 안 파일 목록 보기 | `ls src` |
| 파이프 `\|` | 앞 명령의 결과를 뒤 명령에 넘기기 | `cat error.log \| claude -p "원인 분석"` |
| 환경 변수 | 프로그램이 읽어 가는 설정값 | `JAVA_HOME` |

## 백엔드 기초

| 용어 | 쉬운 설명 | board-api에서는 |
|---|---|---|
| 서버 | 요청을 받아 처리하고 응답을 돌려주는 프로그램 | `./gradlew bootRun`으로 켠 것 |
| 클라이언트 | 서버에 요청하는 쪽 | 브라우저, `curl`, 프런트엔드 앱 |
| API | 서버에 일을 시키는 약속된 창구 | `GET /api/posts` |
| REST API | URL은 "무엇을", HTTP 메서드는 "어떻게"를 나타내는 API 설계 방식 | `DELETE /api/posts/1` = 1번 글 삭제 |
| HTTP 메서드 | 요청의 종류. GET(조회), POST(생성), PUT(수정), DELETE(삭제) | |
| 상태 코드 | 응답 결과를 나타내는 숫자. 200 성공, 201 생성됨, 400 잘못된 요청, 404 없음, 500 서버 오류 | 없는 글 조회 → 지금은 500 (버그!) |
| JSON | 데이터를 주고받는 글자 형식 | `{"title":"제목"}` |
| DB | 데이터를 저장하는 창고 | H2 메모리 DB |
| SQL | DB에 일을 시키는 언어 | `SELECT * FROM posts` |
| Controller | 요청을 받아 Service에 넘기는 계층 | `PostController` |
| Service | 실제 업무 규칙을 처리하는 계층 | `PostService` |
| Repository | DB에 저장하고 꺼내오는 계층 | `PostRepository` |
| Entity | DB 테이블과 연결된 자바 클래스 | `Post`, `Member` |
| DTO | 요청이나 응답으로 주고받는 데이터 묶음 | `PostRequest`, `PostResponse` |
| JPA | 자바 객체를 DB에 저장하게 도와주는 표준. Spring에서는 Hibernate가 실제로 일해요 | `JpaRepository` |
| N+1 문제 | 목록 1번 조회했는데 연관 데이터 때문에 SQL이 N번 더 실행되는 문제. 면접 단골 질문 | 게시글 목록 조회 |
| 예외 처리 | 문제가 생겼을 때 서버가 죽지 않고 알맞은 응답을 주게 하는 것 | `@RestControllerAdvice` |
| 입력값 검증 | 잘못된 값이 들어오면 저장 전에 막는 것 | `@NotBlank`, `@Valid` |
| 테스트 코드 | 코드가 의도대로 동작하는지 자동으로 확인하는 코드 | JUnit 5 |
| Gradle | 라이브러리 내려받기, 빌드, 테스트 실행을 맡는 도구 | `./gradlew build` |

## Git

| 용어 | 쉬운 설명 | 예시 |
|---|---|---|
| 저장소(Repository) | Git이 변경 이력을 관리하는 폴더. 위의 JPA Repository와는 다른 말이에요 | `board-api/` |
| 커밋(Commit) | 지금 상태를 이력에 저장하는 것. 게임의 세이브와 비슷해요 | `git commit -m "fix: 404 처리"` |
| 브랜치(Branch) | 원본을 건드리지 않고 따로 작업하는 갈래 | `feature/comment-api` |
| PR(Pull Request) | "내 브랜치를 합쳐 주세요"라는 요청. 팀원이 코드를 리뷰해요 | GitHub의 PR |
| diff | 무엇이 바뀌었는지 보여 주는 비교 결과 | `git diff` |
